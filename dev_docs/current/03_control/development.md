Setup, testing, building, and deployment instructions.

## Environment Setup

### Prerequisites
- Python 3.10+ (3.11 recommended)
- pip or conda
- Git

### Clone & Install

```bash
# Clone repository
git clone https://github.com/detanaputra/Project_Stella.git
cd Project_Stella

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Install development dependencies
pip install -r requirements-dev.txt  # For testing, linting, etc.
```

### requirements.txt

Pinned to the installed set (D-008) — reproducibility is non-negotiable for a tool shipped to researchers.

### Example Unit Test

```python
# tests/test_models/test_app_state.py
import pytest
from app.models.app_state import AppState

def test_app_state_initialization():
    """Test AppState initializes with defaults"""
    state = AppState()
    assert state.selected_algorithm == "BERTopic"
    assert state.analysis_in_progress == False
    assert state.current_result is None

def test_app_state_subscribe():
    """Test observer pattern"""
    state = AppState()
    called = []
    
    state.subscribe(lambda s: called.append(s))
    state.selected_file_path = "test.csv"
    state.notify()
    
    assert len(called) == 1
    assert called[0].selected_file_path == "test.csv"
```

### Example Integration Test

```python
# tests/test_controllers/test_app_controller.py
import pytest
from app.models.app_state import AppState
from app.controllers.app_controller import AppController
from tests.fixtures import sample_csv_path

def test_on_file_selected():
    """Test file selection updates state"""
    state = AppState()
    controller = AppController(state)
    
    controller.on_file_selected(sample_csv_path())
    
    assert state.selected_file_path == sample_csv_path()
    assert len(state.file_preview) > 0

def test_on_algorithm_changed():
    """Test algorithm change resets parameters"""
    state = AppState()
    controller = AppController(state)
    
    controller.on_algorithm_changed("LDA")
    
    assert state.selected_algorithm == "LDA"
    # Verify LDA default params are set
    assert 'num_topics' in state.algorithm_params
```

## Building & Distribution

### Create Executable with PyInstaller

```bash
# Install PyInstaller
pip install pyinstaller

# Build single-file executable
pyinstaller --onefile --windowed --name "BERTopic GUI" main.py

# Output in dist/ folder
ls dist/
```

### PyInstaller Configuration (pyinstaller-config.spec)

```python
# Auto-generated by PyInstaller, customize as needed
a = Analysis(
    ['main.py'],
    pathex=[],
    binaries=[],
    datas=[],
    hiddenimports=['sklearn', 'bertopic'],
    # ... etc
)
```

## Troubleshooting

### "Module not found" Error

```bash
# Make sure you're in virtual environment
source venv/bin/activate

# Reinstall dependencies
pip install -r requirements.txt
```

### ttkbootstrap Import Error

```bash
# Reinstall with specific version
pip install ttkbootstrap==1.6.1
```

### BERTopic Model Download Fails

```bash
# BERTopic downloads embedding model on first use
# This requires internet connection
# If behind proxy, set environment variables:
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=https://proxy.example.com:8080
```

### Tests Fail with "No module named 'app'"

```bash
# Run pytest from the project root (where the `app/` package lives)
export PYTHONPATH="${PYTHONPATH}:$(pwd)"
pytest
```

## Continuous Integration (GitHub Actions)

Create `.github/workflows/tests.yml`:

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ['3.10', '3.11']
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python ${{ matrix.python-version }}
      uses: actions/setup-python@v4
      with:
        python-version: ${{ matrix.python-version }}
    
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r requirements.txt
    
    - name: Run tests
      run: pytest --cov
    
    - name: Upload coverage
      uses: codecov/codecov-action@v3
```

## Adding a New Algorithm

### Checklist

- [ ] Create `app/models/algorithms/your_algo.py`
- [ ] Implement `BaseAlgorithm` (train, get_default_params, get_param_schema, algorithm_name)
- [ ] Add to `AVAILABLE_ALGORITHMS` registry in `__init__.py`
- [ ] Write unit tests in `tests/test_models/test_algorithms/test_your_algo.py`
- [ ] Document parameters in docstring
- [ ] Test UI parameter form regenerates
- [ ] Test end-to-end workflow

### Example: Add NMF

```bash
# 1. Create file
touch app/models/algorithms/nmf.py

# 2. Implement NMFAlgorithm (follow API.md BaseAlgorithm contract)

# 3. Update registry
# In app/models/algorithms/__init__.py:
# AVAILABLE_ALGORITHMS['NMF'] = NMFAlgorithm

# 4. Test
pytest tests/test_models/test_algorithms/test_nmf.py

# 5. Manual test: Run app, select NMF from dropdown, verify form appears
python main.py
```
